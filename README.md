# FlowTicket 企业级工单协同处理系统

## 一、项目简介

FlowTicket 是一个基于 Spring Boot + MyBatis + MySQL 开发的企业级工单协同处理系统，主要面向企业客服、校园平台、在线教育系统、内部问题反馈等场景。

系统支持普通用户提交工单、管理员分配工单、客服人员处理工单、用户确认关闭工单，并通过工单状态流转、回复记录、操作日志和数据统计等功能，实现完整的问题处理闭环。

本项目重点体现后端系统中的用户认证、角色权限控制、业务状态流转、数据持久化、接口设计和后台统计能力。

---

## 二、项目特点

- 基于 Spring Boot 3.x 构建后端服务
- 使用 MyBatis 简化数据库操作
- 使用 MySQL 存储用户、工单、回复、日志等核心数据
- 支持 JWT 登录认证
- 支持管理员、客服人员、普通用户三类角色
- 支持工单提交、分配、处理、回复、关闭等完整流程
- 支持工单状态流转控制，避免非法状态变更
- 支持工单操作日志记录，便于问题追踪
- 支持后台统计分析，如工单数量、状态分布、分类占比等
- 预留附件上传、Redis 限流、消息通知、定时任务等扩展能力

## 四、系统角色

系统主要包含三类用户角色：

### 1. 普通用户

普通用户主要负责提交和查看自己的工单。

权限包括：

- 用户注册
- 用户登录
- 提交工单
- 查看自己的工单列表
- 查看工单详情
- 回复自己的工单
- 确认关闭工单

### 2. 客服人员

客服人员主要负责处理管理员分配给自己的工单。

权限包括：

- 查看分配给自己的工单
- 回复工单
- 修改工单处理状态
- 将工单提交给用户确认
- 查看个人处理记录

### 3. 管理员

管理员拥有系统最高权限，负责工单管理和人员管理。

权限包括：

- 查看全部工单
- 分配工单给客服
- 修改工单优先级
- 管理用户
- 管理工单分类
- 查看操作日志
- 查看后台统计数据

## 五、核心功能模块

### 1. 用户认证模块

实现用户注册、登录、用户信息查询等功能。

主要功能：

- 用户注册
- 用户登录
- JWT Token 生成
- 登录用户身份解析
- 用户角色识别
- 用户状态校验

---

### 2. 工单管理模块

工单管理是系统核心模块。

主要功能：

- 用户提交工单
- 查询工单列表
- 查询工单详情
- 管理员分配工单
- 客服处理工单
- 用户确认关闭工单
- 工单驳回
- 工单状态修改

工单状态设计：

| 状态值 | 状态名称 | 说明 |
|---|---|---|
| 0 | 待受理 | 用户刚提交，等待管理员分配 |
| 1 | 处理中 | 已分配给客服，客服正在处理 |
| 2 | 待确认 | 客服已处理，等待用户确认 |
| 3 | 已关闭 | 工单处理完成 |
| 4 | 已驳回 | 工单不符合处理条件，被驳回 |

---

### 3. 工单回复模块

用于记录用户和客服之间的沟通过程。

主要功能：

- 用户回复工单
- 客服回复工单
- 查看工单回复记录
- 按时间顺序展示沟通内容

---

### 4. 工单分类模块

用于对工单进行分类管理。

常见分类：

- 账号问题
- 支付问题
- 课程问题
- 系统故障
- 功能建议
- 其他问题

---

### 5. 操作日志模块

系统会记录工单关键操作，方便后续追踪。

记录内容包括：

- 创建工单
- 分配工单
- 修改状态
- 客服回复
- 用户确认
- 工单关闭
- 工单驳回

---

### 6. 数据统计模块

管理员后台可以查看系统运行情况。

统计内容包括：

- 今日新增工单数
- 待处理工单数
- 处理中工单数
- 已关闭工单数
- 工单分类占比
- 最近 7 天工单趋势
- 客服处理数量排行

## 六、工单状态流转说明

系统对工单状态流转进行限制，避免出现非法状态变更。

正常流程：

```text
用户提交工单
    ↓
待受理
    ↓
管理员分配
    ↓
处理中
    ↓
客服处理完成
    ↓
待用户确认
    ↓
用户确认
    ↓
已关闭
```

特殊流程：

```text
待受理 → 已驳回
处理中 → 已关闭
```

限制规则：

- 普通用户只能提交工单和确认关闭自己的工单
- 客服只能处理分配给自己的工单
- 管理员可以查看全部工单并进行分配
- 已关闭工单不能继续修改
- 已驳回工单不能继续处理
- 工单状态修改时必须记录操作日志

## 七、项目亮点

1. 设计了完整的工单业务流程，覆盖提交、分配、处理、确认、关闭等核心环节。
2. 基于角色进行权限控制，区分管理员、客服人员和普通用户的操作范围。
3. 通过工单状态流转规则，避免非法状态修改，保证业务数据一致性。
4. 设计操作日志机制，记录关键业务操作，提升系统可追踪性。
5. 使用 MyBatis-Plus 简化基础 CRUD，提高开发效率。
6. 通过后台统计接口，为管理员提供工单处理情况的数据支持。
7. 项目结构清晰，便于后期扩展 Redis、消息通知、文件上传、AI 辅助回复等功能。
